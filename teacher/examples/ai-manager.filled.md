# 範例：填好的「AI 店長」Agent（只列學生要填的欄位）

職責：在官方標準關裡，用試算工具試出最好的五天策略，再用瀏覽器實際玩一次驗證。
理由：試算很快，可以試很多版；但最後要在畫面上玩過，才能確認試算沒有出錯。

勾選：
- [x] `pricing-rules` ── 負責：每一版策略的定價
- [x] `result-review` ── 負責：讀試算結果，決定下一版怎麼改
- [x] `demand-estimate` ── 負責：決定每樣菜備幾份
- [x] `reorder-check` ── 負責：最後替最好的一版附上補貨清單（不影響分數，但店長回報要完整）
- [x] 試算工具 ── 負責：一次算完五天，比較每一版
- [x] 瀏覽器 MCP ── 負責：最後實際玩一次驗證
- [ ] `change-feature` ── 不勾：店長不准改遊戲程式

工作循環第 5 步：至少試 5 版。

多一條禁止事項：不准刪除或覆蓋舊版策略檔。
理由：留著每一版，才能比較是哪個修改讓分數變好。

多看的欄位：每一版比上一版改了哪三個地方。
理由：我想知道 AI 是怎麼一步一步變強的。
