# 範例：填好的「結果檢討」Skill 對症下藥表

| 看到的現象 | 代表的問題 | 下一次怎麼改 |
|---|---|---|
| 賣完買不到很多 | 備貨太少 | 那樣菜多備一些（注意合計不能超過 80 份） |
| 報廢 15 份以上 | 備貨太多，還要付大型清運費 | 報廢最多的那樣菜減少到「賣出量 + 2」 |
| 嫌太貴很多 | 價格超過客人預算 | 嫌貴最多的那天，把相關的菜降 5～10 元 |
| 想吃的沒上架很多 | 上架的菜跟客人想吃的對不上 | 把賣最少的那樣換成客人想吃的那樣 |
| 因為討厭的菜不進門 | 上架了某些客人討厭的菜 | 比較「討厭的人數」和「愛吃的人數」，少的那邊就不上架 |
| 星等往下掉 | 滿意的人太少，可能是定價太高或缺貨 | 前一天的定價降回建議售價以下，或補足最多人想吃的那樣 |
| 自己發現的：第 5 天還有很多錢沒花 | 最後一天太保守 | 最後一天加開 200 元宣傳，並多備熱賣的菜 |
