# 補貨檢查

> 這是**挖空模板**。標 ★ 的地方要你自己填。
> 重點是「從資料找出要補的貨，數字一定要從試算結果抄，不能自己編」。

## 什麼時候用

跑完 `npm run simulate` 之後，想知道倉庫哪些原料要補時。AI 店長回報時也會用它附上補貨清單。

## 資料從哪裡來

在 `web-lab` 資料夾執行：

```text
npm run simulate -- plans/策略檔.json --json
```

每一天的 `inventory` 欄位有每種原料的盤點結果：

| 欄位 | 意思 |
|---|---|
| `sku`、`name` | 原料代號、名稱 |
| `left` | 打烊剩幾份 |
| `rushBuy` | 今天臨時加購幾份 |
| `safety` | 安全量 |
| `status` | `ok` 正常、`low` 需要補貨、`out` 缺貨 |
| `reorder` | 建議追加叫貨幾份 |

## 步驟

1. 執行上面的指令，讀每一天的 `inventory`
2. 只挑出 `status` 不是 `ok` 的原料

## 回報格式

```text
策略檔：
第 N 天：
  缺貨：原料（代號）剩 … 份、臨時加購 … 份、建議叫 … 份
  需要補貨：原料（代號）剩 … 份、建議叫 … 份
★ 我想多看一個欄位：
最常缺貨的原料：
```
