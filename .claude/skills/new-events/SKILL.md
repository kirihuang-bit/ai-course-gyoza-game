# 營業事件製作（延伸）

## 什麼時候用

想替遊戲設計另一組五天的事件（天氣、團購、節日）時。

## 格式（每一天一筆）

| 欄位 | 限制 |
|---|---|
| day | 1～5 |
| event | 事件名稱，10 字以內 |
| eventPct | 客人人數倍率，70～130 的整數（100 = 不變） |
| forecast | 前一天公布的預告，30 字以內，只給線索、不給確切人數 |
| task | 當日任務：一句話、可以用數字判定、獎金 100～200 元 |

## 步驟

1. 讀 `web-lab/src/game/days.js`，了解現有格式
2. 產生五天草案，用表格給使用者看
3. 使用者確認後，存到 `docs/drafts/events-<主題>.md`
4. **不准直接修改 `days.js`**（老師檔）。要正式使用，由老師決定

## 檢查

- 五天都有，day 不重複
- eventPct 在範圍內，五天平均不要偏離 100 太多（90～110）
- 每個任務都寫得出「達成條件」，例如「報廢 0 份」，不能是「表現良好」
- 預告和事件對得上（例如預告說下雨，事件就要是下雨）
