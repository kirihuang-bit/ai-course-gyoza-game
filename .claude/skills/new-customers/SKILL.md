# 客人資料製作

> 這是**挖空模板**。標 ★ 的地方要你自己填，每一格都要寫「理由」。
> 填好之後，AI 每次幫你做客人都會照這份規則，不用你每次重講。

## 什麼時候用

使用者說「幫我做一批新客人」「我要出題考同學」時。

## 每位客人必須有這些欄位

| 欄位 | 意思 | 限制 |
|---|---|---|
| name | 名字 | 不可用真實名人、不可重複 |
| intro | 一句話介紹 | 20 字以內 |
| budget | 一餐的總預算 | 30～150 的整數 |
| wants | 想吃的東西，有先後順序 | 1～2 樣，只能從菜單選 |
| hates | 討厭的東西 | 最多 1 樣，沒有就寫 null |
| days | 出現在第幾天 | 1～5 的整數陣列，例如 [1, 3] |
| count | 當天的基本人數 | 1～12 的整數 |
| lines | 五種情況的台詞 | 每句 20 字以內，五句都要有 |

`lines` 的五種情況：

- `bought`：買到了
- `hated_on_menu`：討厭的東西有上架，不進門
- `not_on_menu`：想吃的沒上架
- `sold_out`：想吃的賣完了
- `too_expensive`：太貴不買

## 工作步驟

1. 先讀 `web-lab/src/game/menu.js`，確認菜單與建議售價
2. 先產生 3 位客人，用表格給使用者看，**不要直接寫檔**
3. 使用者說 OK，才寫入 `web-lab/src/game/customers/my-customers.json`（整個檔案是一個陣列）
4. 寫完執行下面的檢查，逐條回報結果

## 寫完必須檢查

- 必填欄位都有，五句台詞都有
- budget 在 30～150 之間，也在上面填的預算範圍內
- wants、hates 只用菜單上的品項
- 沒有重複的名字
- 每一天的 count 加總不超過 50
- 在 `web-lab` 資料夾執行 `npm run check`，確認「客人包檢查」仍然全部 PASS
- 打開遊戲，在「客人包」選「我的客人包」，確認沒有出現紅色錯誤
